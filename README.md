# EasyGIF

EasyGIF 是一个简易的 GIF 录屏工具：先框选区域，再开始/停止录制，支持剪辑预览后保存 GIF。

~~可以用来给你喜欢的动画角色制作表情包~~

## 环境
- Python3.10+
